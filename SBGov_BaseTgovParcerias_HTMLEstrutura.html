Como ler o mapa Da esquerda para a direita é o caminho do dinheiro: o governo federal publica um programa (e às vezes indica um beneficiário de emenda parlamentar); o município responde com uma proposta — que é o recurso; quando aprovada, a proposta gera uma parceria — o instrumento celebrado; e o resto detalha essa parceria (conta bancária, documento hábil, ordem de pagamento, empenho). item_proposta está marcada como inalcançável: existe no modelo, mas a API não oferece nenhum filtro que a ligue a uma proposta específica (ver Documentação).
